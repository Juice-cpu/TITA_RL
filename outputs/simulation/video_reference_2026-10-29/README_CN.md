# 视频参考走廊仿真结果（2026-10-29）

本目录保存基于用户提供视频抽帧后建立的 Isaac Sim 仿真课程结果。视频可见结构为室内长走廊、转弯/开阔段和楼梯；未观察到低矮狗洞，因此低顶棚段作为独立可控训练条件加入，而不是声称来自视频。

## 结果

- 冻结 PPO checkpoint：`video_corridor_ppo_continuation_12000.pt`
- 独立测试种子：`10055`
- 结果：成功到达目标，完成稳定保持；`evaluation_status=success`
- 模态序列：`LOW → MID → HIGH → MID`
- 独立测试切换次数：`4`
- 独立测试步数：`5031`；执行路径长度：`8.7516 m`
- 台阶支持区稳定完成：`true`
- 碰撞、速度、高度、姿态、净距等硬失败：全部为 `0`
- 独立测试没有安全等待步；训练回合的安全等待步为 `3800`，说明策略仍有明显保守行为

## 场景边界

- 低顶棚高度：`0.58 m`，运行时宽度：`2.0 m`
- 台阶：已标定的单级 `0.01 m` 台阶代理；不是视频中真实楼梯尺寸，也不是多级楼梯能力证明
- 现有全身几何标定支持的 elevated-support 上限为 `0.015 m`；尝试直接运行三阶 `0.01 m` 累计高度时被安全校验拒绝，因此没有伪造三阶结果
- 该结果是在 A* 有限候选路径集合和可行模态集合内的联合决策，不是连续空间全局最优性证明
